# Security Policy

At **Vib Tools**, security and user privacy are foundational engineering principles. Because **Email Grouper** processes sensitive contact data, our architecture is strictly zero-server and client-side only.

---

## Supported Versions

We actively maintain and provide security fixes for the latest release on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

**Please do NOT report security vulnerabilities via public GitHub issues, discussions, or pull requests.**

If you discover or suspect a security vulnerability or sensitive data leakage:

1. Send an email to **[support@vib.tools](mailto:support@vib.tools)**.
2. Include:
   - A clear description of the vulnerability.
   - Steps to reproduce or proof-of-concept (PoC).
   - Any potential impact on user data or browser environment.
   - Your contact details for coordinated disclosure and credit.
3. You can also copy **[hello@vib.tools](mailto:hello@vib.tools)** if you do not receive a response within 48 hours.

---

## Response Timeline

- **Initial acknowledgment**: Within 48 hours (GMT+6).
- **Assessment and triage**: Within 5 business days.
- **Fix deployment & release**: As quickly as possible depending on severity.

We appreciate the efforts of security researchers and engineers who practice responsible coordinated disclosure.
